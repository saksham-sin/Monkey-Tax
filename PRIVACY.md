# Privacy Policy for MonkeyTax

Last updated: October 2026

MonkeyTax is built on a strict privacy-first, client-side model:

1. **Zero Data Collection**: MonkeyTax does not collect, track, log, or transmit any personally identifiable information, browsing history, or message content.
2. **Local Processing**: Prompt evaluations, token counting heuristics, and compute calculations execute 100% locally within your browser's runtime memory.
3. **Storage**: Usage statistics (e.g., prompt counts, estimated water, and energy figures) are stored solely on your local device via `chrome.storage.local`.
4. **No External Communications**: MonkeyTax makes zero network requests and contacts zero remote servers or telemetry providers.

For questions or source inspection, visit: https://github.com/saksham-sin/monkey-tax
